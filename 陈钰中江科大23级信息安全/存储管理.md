# 硬盘设备命名

 **传统 IDE/PATA 硬盘**

- **命名格式**: `hd[a-z]`
  - **示例**:
    - 第一块 IDE 硬盘: `/dev/hda`
    - 第二块 IDE 硬盘: `/dev/hdb`
  - **特点**:
    - 逐渐淘汰，现代系统更多使用 SATA/SCSI 命名规则

**SATA/SCSI/SAS/USB/NVMe 硬盘**

- **命名格式**:
  - **SATA/SCSI/SAS/USB**: `sd[a-z]`
    - 示例:
      - 第一块 SATA 硬盘: `/dev/sda`
      - 第二块 SATA 硬盘: `/dev/sdb`
  - **NVMe SSD**: `nvme[0-9]n[0-9]`
    - 示例:
      - 第一个 NVMe 控制器上的第一个命名空间: `/dev/nvme0n1`
      - 第二个 NVMe 控制器上的第一个命名空间: `/dev/nvme1n1`

**虚拟设备**

- **命名格式**: `vd[a-z]` (常见于虚拟化环境如 KVM)
  - 示例:
    - 第一块虚拟硬盘: `/dev/vda`
    - 第二块虚拟硬盘: `/dev/vdb`

# 分区表

分区表是存储在磁盘起始扇区中的数据结构，用于记录磁盘的分区布局（如分区数量、大小、类型等）。它相当于磁盘的“目录”，告诉操作系统如何访问和管理不同分区。

## 分区表作用

- **定义分区边界**：记录每个分区的起始和结束位置（柱面/扇区）。
- **标识分区类型**：如 NTFS、FAT32、Linux swap 等。
- **支持多系统启动**：允许不同操作系统共存于同一磁盘的不同分区。
- **保护数据隔离**：防止一个分区的错误影响其他分区。

## 分区表类型

### MBR（Master Boot Record）

- **特点**：
  - 传统分区表，兼容性极强（支持 BIOS 启动）。
  - 最大支持 **2TB** 磁盘，最多 **4个分区**
  - 有两种分区：主分区、拓展分区
    - 拓展分区可以在逻辑上划分多个区域，但是在分区表中算在一个分区内
  - 分区信息存储在磁盘的第一个扇区（512字节）。
- **结构**：
  - **引导代码**（前446字节）：用于启动操作系统。
  - **分区表**（64字节）：记录4个分区的信息。
  - **结束标志**（2字节：`0x55AA`）。

### GPT（GUID Partition Table）

- **特点**：
  - 现代分区表，支持 **UEFI 启动**。
  - 最大支持 **18EB（艾字节）** 磁盘，理论上无限分区数量（实际限制由操作系统决定）。
  - 具有冗余备份，更安全。
- **结构**：
  - **保护性MBR**（兼容旧系统）。
  - **GPT头**：记录分区表位置和校验信息。
  - **分区条目数组**：每个条目128字节，可包含多个分区。
  - **备份GPT头**：防止主分区表损坏。

### 类型对比

| **特性**         | **MBR**                          | **GPT**                          |
| :--------------- | :------------------------------- | :------------------------------- |
| **最大磁盘容量** | 2TB                              | 18EB（1EB=1024PB）               |
| **最大分区数量** | 4个主分区（或扩展分区+逻辑分区） | 理论上无限（Windows限制为128个） |
| **启动方式**     | 仅支持 BIOS                      | 支持 UEFI 和 BIOS（需兼容模式）  |
| **安全性**       | 无校验，易损坏                   | CRC校验，备份分区表              |
| **兼容性**       | 所有操作系统                     | 较新系统（Windows Vista+/Linux） |

# 文件系统

当我们在硬盘上完成分区后，还需要为这些分区建立一套"管理规则"——这就是文件系统。简单来说，文件系统决定了数据在磁盘上的存储和读取方式，就像图书馆需要一套图书分类管理系统一样。

## 文件系统的核心作用

文件系统主要解决三个关键问题：

1. **存储规范**：数据应该按照什么格式存放
2. **读取规则**：如何快速准确地找到所需数据
3. **空间管理**：如何高效利用磁盘空间

## Linux文件系统的主要类型

虽然Linux支持数十种文件系统，但主要分为两大类：

### 日志式文件系统

- **特点**：记录操作日志，意外断电时能快速恢复
- **代表**：ext4、XFS、Btrfs
- **适用场景**：需要高可靠性的场景
